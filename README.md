# 회복 탄력성 테스트

한화그룹 신입사원을 위한 자기점검·학습 웹사이트입니다.

## 사용하기

`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속합니다. 별도의 설치나 빌드가 필요하지 않습니다. 디자인, 로고, 애니메이션, 데이터, 한글 글꼴과 PDF 라이브러리를 하나의 HTML 파일에 포함했습니다.

## 주요 기능

- 닉네임 입력과 16문항 자기점검
- 총점과 6개 학습 영역의 참고 프로필
- 결과 대시보드·상세 리포트·도서 및 영화 추천
- 14일 실천 계획과 완료 체크
- 한글 텍스트를 선택할 수 있는 A4 2쪽 요약 PDF
- 기기 보관 선택과 데이터 삭제

## 데이터와 해석

응답은 방문자의 브라우저에서 처리되며 서버로 전송되지 않습니다. 현재 탭의 진행 상태는 세션 저장소에, 사용자가 보관을 선택한 결과는 기기 저장소에 저장합니다. 조직별 응답 수집 기능은 포함하지 않습니다.

이 서비스는 자기이해·학습 참고용이며 의학적 진단이나 인사평가용 검사가 아닙니다. 6개 영역의 문항 배정은 서비스의 학습용 분류로, 원저자의 공식 하위척도나 검증된 요인구조가 아닙니다.

## 출처

문항·해석: 게일 가젤, 『하버드 회복탄력성 수업』, 현대지성. 사용자 제공 자료를 바탕으로 구성했습니다.

한화 로고는 공식 원본을 사용했습니다. 히어로·썸네일은 브랜드 모티프를 활용한 SVG 연출이며 공식 사진이 아닙니다. 공식 운영·인증 검사로 제공되지 않습니다.

Nanum Gothic의 SIL Open Font License 전문과 jsPDF 2.5.2의 MIT 라이선스 주석을 HTML 안에 포함했습니다. 추천 작품·뉴스의 출처 링크는 서비스 화면에서 확인할 수 있습니다. 뉴스는 2026-10-15 확인 기준이며 자동 갱신되지 않습니다.

## GitHub Pages 설정

저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/(root)`를 선택합니다. `index.html`을 수정해 푸시하면 새 버전이 배포됩니다. `.nojekyll`은 정적 HTML을 그대로 배포하기 위한 파일입니다.
